01 · Summary

Not ready yet, and here is why

We found problems that need fixing before this is ready.

What we tested

We built a full sample proposal using only the admin screens, then compared what came out with the approved design on screen, in light and dark themes, and as a downloaded PDF.

What we found

The look of the cover, option cards, roadmap, tables and printed cover all match. But we found 8 issues: one blocker (a crash, now fixed), five major issues and two minor ones. 4 are still open.

What it means for you

Right now a proposal cannot be authored end to end so that it matches the approved design, and the PDF is not clean enough to send to a client.

What happens next

We are fixing the open issues and will re-test them. We will send an updated report when the major issues are verified.

04 · Issues found

8 issues found, 4 still open

Ordered by severity, open issues first. Status is as of October 2, 2026.

Issue D2

BlockerFixed & verified

Creating a new proposal fails with an error when a diagram image is attached

What happens

If you upload a diagram image and any other field on the form has a mistake, the whole screen shows an error page and everything you entered is lost.

Steps to reproduce

  1. Open the New proposal screen.
  2. Add a section, set its type to Diagram and upload an image.
  3. Add a line item set to "Pick one option" without choosing an option group.
  4. Select Create proposal.

Expected

The form reopens with a message about the missing option group, and your image and entries are kept.

Actual

An error page appears and nothing is saved.

Fixed in PR #102 and PR #103; re-tested October 2, 2026.

Root cause (appendix)

Issue D3

MajorOpen

Phases and option groups added on the same screen cannot be chosen for a line item

What happens

A first-time author who adds phases, option groups and line items in one pass cannot assign a line item to the phase or group they just added.

Steps to reproduce

  1. Open the New proposal screen.
  2. Add a phase and an option group.
  3. Add a line item and open its Phase and Option group choices.

Expected

The phase and option group you just added are listed.

Actual

Only phases and groups from an already saved proposal are listed.

Open as of October 2, 2026.

Root cause (appendix)

Issue D4

MajorOpen

The diagram image shows as a broken picture in the PDF

What happens

The diagram looks right on screen in both themes, but the downloaded PDF shows a broken-image icon above the caption.

Steps to reproduce

  1. Send a proposal that has a diagram section with an image.
  2. Download its PDF.
  3. Go to the diagram page.

Expected

The diagram image appears in the PDF.

Actual

A broken-image icon appears above the (correct) caption.

Open as of October 2, 2026.

Root cause (appendix)

Issue D5

MajorOpen

The PDF includes the website's menu bar and footer

What happens

The on-screen proposal is clean, but the PDF adds the public website's black menu bar above the cover and an extra last page of website footer links.

Steps to reproduce

  1. Send a proposal.
  2. Download its PDF.
  3. Look at page 1 and the final page.

Expected

The PDF contains only the proposal.

Actual

A black header bar with a menu icon sits above the cover, and a fifth page shows the website footer.

Open as of October 2, 2026.

Root cause (appendix)

Issue D1

MajorFixed, not yet re-tested

The proposal's headline and label above it cannot be set

What happens

Every proposal falls back to the generic heading "Proposal for" plus the company name, with no label above it, so the approved headline cannot be reproduced.

Steps to reproduce

  1. Open the New proposal screen.
  2. Look through the Details section for a title or label field.

Expected

Title and label fields in Details.

Actual

There are no such fields.

Fixed in PR #101; awaiting re-test.

Root cause (appendix)

Issue D6

MajorDeferred

The proposal has no table of contents

What happens

The approved design has a Contents list. The built proposal has nothing like it.

Steps to reproduce

  1. Open any authored proposal.
  2. Look below the cover for a Contents list.

Expected

A Contents list linking to each section.

Actual

No Contents list.

Deferred. Reason: Being delivered as its own piece of work rather than as part of this round.

Root cause (appendix)

Issue D7

MinorOpen

Section headings do not match the approved design

What happens

The design shows a small coloured label above a plain heading. The built proposal joins the number and title into one heading.

Steps to reproduce

  1. Open any authored proposal.
  2. Compare a section heading with the approved design.

Expected

A coloured label above a plain heading.

Actual

One combined heading with a grey number.

Open as of October 2, 2026.

Root cause (appendix)

Issue D8

MinorWon't fix

The "Body" field in Details never appears in the proposal

What happens

Authors naturally fill in the first field on the form, and that text silently disappears from what the client sees.

Steps to reproduce

  1. Open the New proposal screen.
  2. Type text into the Body field in Details.
  3. Preview the proposal.

Expected

The text appears somewhere, or the field is clearly marked as not shown.

Actual

The text appears nowhere.

Won't fix. Reason: The field is meant for private notes; we will relabel it so that is clear.

Root cause (appendix)

Notes (not issues)

ObservedNote N1

The preview screen cannot make a PDF

The PDF only exists after a proposal has been sent; the admin preview has no PDF option. This is how it is built, not a fault.

What we recommend: Mention it in any author guidance so nobody looks for a PDF button on the preview.

The sample records were deleted afterwards, and the live product was not changed.
